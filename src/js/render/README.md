# src/js/render/
- `tuvi-render.js`: render UI từ JSON, highlight, an sao lưu theo năm xem hạn; hiển thị Năm hạn trong center info (chữ ô giữa 12px, năm hạn 14px). Với method TTL, render merge thêm bảng lưu method-specific từ `ANSAO_THAITHULANG.TABLES` (`LUU_SAO_THEO_CHI` / `LUU_SAO_THEO_CAN`, gồm `L.Đại Hao`/`L.Tiểu Hao`).
- Nhãn sức mạnh sao hiển thị theo chuẩn `M/V/Đ/B/H`.
- Render chỉ đọc JSON do `TUVI_LOGIC.compute` trả về; quy tắc an sao theo từng phương pháp nằm ở `trungchauphai.js` / `thaithulang.js` và bảng chung trong `data.js` (không nhúng logic an sao vào render).
- `tuvi-render-modules.js`: module tách riêng cho `tuvi-render` (hằng số lớn + rule engine + pill engine Triệt/Tuần/L.Triệt/L.Tuần + center renderer) để giảm kích thước file chính và tối ưu token khi bảo trì. Ô `.center` có `.center-bg` chứa SVG Âm Dương bản gọn (không còn vòng quẻ xung quanh; chỉ hiện khi nền ô giữa là Âm Dương vector) và slogan `resources/sologan-laso/dich_hoc_tinh_hoa3.png` neo dưới phải (cao 2/5 `.center-bg`, `right: 5px`) và ấn `resources/sologan-antin/an_tin_icon3.png` ngay dưới (rộng bằng slogan, `padding-top: 5px`, `bottom: 10px`); đã bỏ hẳn các dòng phân cách ngang trong bảng info center (có `Ngày DL` trên `Ngày AL`, một hàng trống dưới `Cục`, ba dòng Âm Dương thuận/nghịch, quan hệ Mệnh Cục và `Thân cư` in đậm trên web và mobile). Ảnh nền qua `.center::before` / `--laso-center-bg` (`theme-config.js` + `grid.css`).
- Render layer chỉ consume output từ `TUVI_LOGIC.compute(...)`; không đặt dữ liệu an sao đặc thù method trong render.
